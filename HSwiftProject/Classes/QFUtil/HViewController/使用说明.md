# 优化文件使用说明与示例

## 1. HBaseController.swift

### 功能说明
HBaseController 是一个基础视图控制器类，提供了通用的 UI 设置、导航栏控制和生命周期管理功能。

### 核心功能
- 基础 UI 设置（背景色、触摸响应等）
- 导航栏样式控制
- 状态栏样式自动调整
- 子视图控制器管理
- 设备旋转支持

### 使用示例
```swift
class MyViewController: HBaseController {
    override func viewDidLoad() {
        super.viewDidLoad()
        // 自定义设置
    }
    
    // 自定义导航栏样式
    override var preferredNavigationBarColor: UIColor {
        return .systemBlue
    }
    
    // 处理视图控制器消失事件
    override func vcWillDisappear(_ type: HVCDisappearType) {
        super.vcWillDisappear(type)
        // 执行清理操作
    }
}
```

## 2. HCusViewController.swift

### 功能说明
HCusViewController 是一个带有自定义导航栏的视图控制器，支持视图模型绑定和导航栏样式定制。

### 核心功能
- 自定义导航栏视图
- 视图模型绑定
- 导航栏样式管理
- 响应式编程支持（RxSwift）

### 使用示例
```swift
class MyCustomViewController: HCusViewController<MyViewModel> {
    init() {
        let viewModel = MyViewModel()
        super.init(viewModel: viewModel)
    }
    
    required init?(coder: NSCoder) {
        fatalError("init(coder:) has not been implemented")
    }
    
    override func viewDidLoad() {
        super.viewDidLoad()
        // 设置导航栏样式
        navShowStyle = .clearBgWhiteBackArrow
    }
    
    override func addSubviews() {
        // 添加自定义子视图
    }
    
    override func bindViewModel() {
        super.bindViewModel()
        // 绑定视图模型其他属性
        viewModel.someObservable
            .subscribe(onNext: { [weak self] value in
                // 处理值变化
            })
            => disposeBag
    }
}
```

## 3. HNavigationItem.swift

### 功能说明
HNavigationItem 是一个自定义的导航栏按钮项，支持标题、图片、点击事件和禁用状态。

### 核心功能
- 标题和图片设置
- 点击事件回调
- 禁用状态样式
- 防抖动处理

### 使用示例
```swift
// 在视图控制器中使用
override func viewDidLoad() {
    super.viewDidLoad()
    
    // 设置左侧按钮
    navigationItem.leftItem.title = "返回"
    navigationItem.leftItem.pressed = { [weak self] in
        self?.naviBack()
    }
    
    // 设置右侧按钮
    navigationItem.rightItem.image = UIImage(named: "settings")
    navigationItem.rightItem.pressed = { [weak self] in
        self?.showSettings()
    }
    
    // 设置禁用状态
    navigationItem.rightItem.isEnabled = false
    navigationItem.rightItem.disableTextColor = .lightGray
}
```

## 4. HNavigationView.swift

### 功能说明
HNavigationView 是一个自定义导航栏视图，包含 UINavigationBar 和导航栏分割线。

### 核心功能
- 导航栏样式定制
- 导航项管理
- 分割线控制

### 使用示例
```swift
// 一般在 HCusViewController 中自动使用，也可手动创建
let navigationView = HNavigationView(frame: .zero)
navigationView.backgroundColor = .white
navigationView.navigationLine.isHidden = false
navigationView.navigationLine.backgroundColor = .lightGray

// 添加到视图
view.addSubview(navigationView)
navigationView.snp.makeConstraints { make in
    make.top.left.right.equalToSuperview()
    make.height.equalTo(UIScreen.topBarHeight)
}

// 使用导航项
navigationView.navigationItem.title = "标题"
```

## 7. UIViewController+HDisappear.swift

### 功能说明
UIViewController 的扩展，提供了视图控制器出现和消失类型的管理，以及返回事件处理。

### 核心功能
- 视图控制器出现类型管理
- 视图控制器消失事件回调
- 统一的返回事件处理
- 导航和模态操作的类型追踪

### 使用示例
```swift
// 处理视图控制器消失事件
override func vcWillDisappear(_ type: HVCDisappearType) {
    super.vcWillDisappear(type)
    
    switch type {
    case .pop:
        print("视图控制器被弹出")
    case .dismiss:
        print("视图控制器被 dismiss")
    case .push:
        print("视图控制器被新页面覆盖")
    case .undefine:
        print("未定义类型")
    }
}

// 使用统一的返回方法
@objc func backButtonTapped() {
    naviBack { 
        print("返回完成")
    }
}
```

## 8. HBaseNaviController.swift

### 功能说明
HBaseNaviController 是一个基础导航控制器，提供了手势返回、屏幕旋转等功能。

### 核心功能
- 全屏返回手势支持
- 手势黑名单管理
- 屏幕旋转支持
- 暗黑模式关闭

### 使用示例
```swift
// 创建导航控制器
let navi = HBaseNaviController(rootViewController: HomeViewController())

// 添加到手势黑名单
navi.addFullScreenPopBlackListItem(someViewController)

// 移除从手势黑名单
navi.removeFromFullScreenPopBlackList(someViewController)

// 设置边缘手势
navi.setupEdgePanGesture()
```

## 9. HNavigationController.swift

### 功能说明
HNavigationController 是 HBaseNaviController 的子类，提供了全屏模态导航控制器的创建方法。

### 核心功能
- 全屏模态导航控制器创建
- 自动设置边缘手势

### 使用示例
```swift
// 创建全屏模态导航控制器
let rootVC = MyViewController()
let navi = HNavigationController.fullScreenModalNavi(rootVC: rootVC)

//  present 导航控制器
present(navi, animated: true, completion: nil)
```
